# CI
CI (`.github/workflows/`) caches `~/.cache/dotfiles-test` (the pinned tools and the fixtures' downloads), gives every job a timeout, and runs `make validate`, `make lint` and `make fixtures` on Ubuntu (and then points the `install` branch at the commit, see [Installation](../installation.md#installing-on-a-fresh-machine)), and `make test` on Arch Linux (in a container whose packages are pinned to an Arch Linux Archive snapshot), Ubuntu and macOS. The macOS job is skipped when no file it tests changed (a `changes` job decides, since macOS minutes cost more), and a skipped job doesn't fail the workflow, so the `install` branch moves only to commits that passed everything that ran, macOS included. Actions are pinned to commit SHAs and kept current by Dependabot; container images, runner labels and `tests/versions.env` are bumped by hand.
