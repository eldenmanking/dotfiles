# Tests
`make test` (`tests/install.sh`) checks behavior, so changes don't break what already works. It runs `install.sh` in scratch home directories, without touching your own: `--help` and `--dry-run` (plus `--reinstall` and `--uninstall`) for every OS and profile, which must leave the home unchanged; a real `--link --gitconfig` install (plus `--shell` where it writes managed blocks) for every OS and profile that only links under `$HOME`, which a second run must not change; and login and interactive bash and zsh loading the resulting startup files. Set `INSTALL_BASH` to test `install.sh` under another bash, e.g. `INSTALL_BASH=/bin/bash make test` for bash 3.2 on macOS. `tests/webterm_smoke.py` is a separate smoke test for webterm, run by hand (see [Webterm](../features/webterm.md#smoke-test)).
