# Lint
`make lint` (`tests/lint/`) checks code quality: the syntax of every shell, zsh, Python and TOML file, shellcheck (plus a second pass for unused variables that skips `UPPER_CASE` globals, which other files read, and variables an `f_return` returns by bare name; `tests/lib.sh` is checked too), the doc comment of every function (a description and a `Usage:` line, plus a `Returns:` line naming what a function that calls `f_return` returns; see `.claude/CLAUDE.md`), a check that one-time installs (`install/oti`) run their state-changing commands through the shown-command helpers (a line can be exempted with a trailing `# oti-ok: <reason>`), actionlint, no bash 4 features or GNU-only flags (`mapfile`, `declare -A`, `readlink -f`, ...) in `install/`, `install.sh` and `scripts/` (`install/oti` runs on a live ISO and is exempt), and no call of a `_`-prefixed helper from a file other than the one defining it. The shellcheck and actionlint versions are pinned in `tests/versions.env`; `make lint` downloads them into `~/.cache/dotfiles-test` on first use and refuses any download that doesn't match its pinned SHA-256.
