# Validation
`make validate` (`tests/validation/`) enforces the repo's structure, which has to keep holding as files are added, moved or removed: the checkout is a directory named `dotfiles`, the tree in [Layout](../layout.md) matches the files tracked by git, `tests/versions.env` pins a SHA-256 for every tool on every platform, every feature is documented and suits the OSes and profiles that use it (see [Writing features](../writing-features.md#feature-docs-and-requirements)), every variant names an OS and profile that go together, the README's OS, Profile and Machine table matches the OSes, profiles, machines and variants, every link path exists, naming single files under `root/`, every `uninstall_feature_<x>` and `capture_feature_<x>` names a feature in `DRY_RUN_FEATURES` (both must honor `--dry-run`), and every feature file that copies files into `/etc` calls `keep_across_steamos_updates` (a grep, with exceptions listed in `tests/validation/features.sh`).
